Ablating the delivered memory.

Analysis November 1, 2026 · Grok 4.3 · reasoning requested as none · synthetic mirrored histories.

Full versus empty+32.6 points

History changes the decision.

Full memory reached 479/576 history-concordant choices, against 291/576 with empty memory. It exceeded empty memory in all 12 scenarios.

These are repeated choices on 24 saved histories, not 3,456 independent agents or 12 independent behavioral axes.

Component delivery cuts12.8% flips

Both delivered components contribute.

Removing beliefs changed 74 paired choices; removing episodes also changed 74. Full-memory repeat disagreement was 11/384 (2.9%).

Cuts occur after recall. Beliefs already helped cue episode selection, so this does not measure their total causal contribution.

Mirrored histories66.3%

Different histories yield different choices.

Mirroring the saved history changed 191/288 full-memory choices, compared with 9/288 (3.1%) without memory.

Swapping only the belief did not reliably transfer the donor pattern. Option-order sensitivity remains material.

Selection under distraction.

GENESIS contextual transfer v1–v4 · synthetic mirrored histories · Grok 4.3 · pilot results, not replication.

New: October 28 breaking-point follow-up. In a separate 512-decision Grok 4.3 sweep across 8/16/32/64-word memory ceilings and 240/960 distractors, contextual SelMem scored 28/32 (87.5%) at 32 and 64 words, compared with 18/32 (56.25%) for lexical retrieval and 14/32 (43.75%) for the frequency summary. At 8 words, the belief statement was cut before the predicted action. Selected ON/OFF/lexical memory strings did not change with load, so this is a compression and serialization pilot, not proof of robustness to model-visible distraction or general RAG superiority. Keep the question open.

What the evidence supports

  • Selective admission and sleep produce inspectable memory changes.
  • Post-recall memory cuts change choices in the versioned context-cued suite.
  • Concrete proposals and selection tradeoffs can be audited.
  • Creative examples justify more controlled investigation.

What still needs demonstrating

  • An independent blind utility–originality advantage over controls.
  • Pre-retrieval lesions separating direct belief delivery from episode cueing.
  • Replication with fresh histories, unrelated behavioral axes and other models.
