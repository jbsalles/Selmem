Six players sit in a circle. Each receives two tokens. A single loop of string is placed in the center; twelve tokens start beside it.

Turn order  
Players take turns clockwise. On your turn, place one token on the string or move one already on it one finger-width along the loop. You may also pass your second token to any neighbor.

Shared objective  
Form a closed “token chain” that uses every token exactly once and returns to its starting point on the string.

End condition  
The loop is complete when twelve tokens sit evenly spaced and the first and last touch.

Failure  
If three consecutive turns pass with no placement or movement, the game ends unfinished.

Recovery rule  
Any player may spend both tokens in one turn to remove any two misplaced tokens and immediately replace them anywhere on the string; play then continues clockwise from the next player.

R177 · game

transplant_a_from_b

Setup  
Six players sit in a circle. Each receives two tokens. A single loop of string lies in the center; twelve tokens start beside it.

Turn order  
Players take turns clockwise. On your turn, place one token on the string or move one already on it one hand-span along the loop. You may also pass your second token to any neighbor.

Shared objective  
Move all twelve tokens once around the loop and back to the start pile using only cooperative placements.

End condition  
The game ends when every token has completed a full circuit and returned, or when no tokens remain on the string and it is a player’s turn with none left to place.

Possible failure  
If the circle breaks (string pulled taut by two opposing pulls) all tokens on the string fall off and are removed from play.

Recovery rule  
Any player may spend both tokens in one turn to retie a broken string, returning one fallen token to the center pile.
